# AEC 闭环回归

这个目录用于第三块 RV1106 板的可重复 AEC/自激回归。它只保存测试方法和脱敏结论；
每轮生成的客户端日志、服务端日志、音频片段和配置快照放入 `runs/`，默认不进入 Git。

每轮测试只改变一个变量，并记录：

- `run_id`、客户端二进制 SHA-256、测试开始/结束时间；
- 播放音量、板级增益、3A profile、VAD/打断阈值；
- 唤醒次数、用户 turn 数、AI 回复数、打断次数、无人工输入产生的新 turn 数；
- ALSA xrun、DSP 失败、队列溢出和连接重建次数；
- 是否出现自激，以及停止测试的原因。

安全边界：

- 不记录 API Key、设备令牌、Wi-Fi 密码或完整认证配置；
- 原始麦克风、硬件 reference 和 AEC 后 PCM 不提交 Git；
- 自动回归必须设置最长时间和最大 AI turn 数，达到任一限制立即停止客户端；
- 录音样本仅用于本地开发回归，不上传远端仓库。

当前基线与每轮结论记录在 [findings.md](findings.md)。
