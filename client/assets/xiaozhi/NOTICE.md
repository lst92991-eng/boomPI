# XiaoZhi emoji assets

The seven generated LVGL image sources in this directory were copied from
`78/xiaozhi-fonts` version 1.5.5, the emoji package used by the XiaoZhi ESP32
project. The package metadata declares the component as MIT licensed.

The underlying Twemoji graphics are licensed under Creative Commons
Attribution 4.0 International (CC BY 4.0). Attribution: Copyright 2020 Twitter,
Inc. and other contributors. Source: <https://github.com/jdecked/twemoji>.

These unmodified 64x64 conversions are retained as reviewed design-source
assets, but boomPI v1.0.0 does not compile or display them. The production
voice page uses `client/assets/ui/voice-orb-v2.rgb565`; any future use of these
Twemoji states must preserve this notice and their attribution.
