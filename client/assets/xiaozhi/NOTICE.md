# XiaoZhi 表情资源

本目录的五个 LVGL 图片来自 `78/xiaozhi-fonts` 1.5.5，也就是小智 ESP32
项目使用的表情包。这里只保留 boomPI 运行状态实际使用的表情；生成后的 C 数组
直接参与编译，不需要在板端解码 PNG。

说明和上述署名。
