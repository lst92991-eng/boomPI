# UI icon font

`tabler-icons-200-subset.ttf` is a small subset of Tabler Icons Webfont
3.46.0. It contains only the outline glyphs used by the 320×240 boomPI UI.

- Source: https://github.com/tabler/tabler-icons
- Package: `@tabler/icons-webfont@3.46.0`
- Style: 2 px outline
- License: MIT; see `TABLER-LICENSE.txt`

The subset is generated from these Unicode code points:

```text
EA19 EA35 EA54 EA61 EA70 EA76 EA8B EA9A EAAD EAC1 EAED EAF0
EB0A EB13 EB20 EB30 EB31 EB38 EB51 EB52 ED23 ED46 ED4A EF8E
F09F F1C3 F1FF
```
