## 3. P1：必须修正

### P1-1 上电时序把手册标注概括得过强，并遗漏 R20 的关键设计事实

**位置：** Markdown 第 44～54 行；PDF 第 4～6 页，图 2-5 至图 2-7。

**当前问题：**

1. 第 44 行把手册图中的 `T0、T1 > 1 ms` 概括成“相邻阶段大于 1 ms”。截图只明确标出 T0/T1，不能扩大为所有相邻电源边沿都满足同一条件。
2. RV1106G 时序图把 `VDD_0V9` 与 `VDD_ARM` 画成两个先后建立的电源节点；当前网表却显示 R20=0 Ω，直接连接 `VDD_0V9` 与 `VDD_ARM_0V9`，U3 的 `CPU_DVDD` 在 R20 后侧。也就是说，本板没有为 `VDD_ARM_0V9` 设置独立 EN 延时。
3. 第 48 行“boomPI 用三组 RC 网络回应这个要求”容易让读者误以为图 2-5 的每一条时序关系都被电路逐项复现。三组 RC 只控制 U4 的 `0.9 V`、`1.35/1.8 V`、`3.3 V` 三个 EN 阶段；它们不能证明 R20 两侧出现手册图中的独立 ARM 延时。

**证据：**

- 当前网表：R20 pin 1=`VDD_0V9`、pin 2=`VDD_ARM_0V9`、value=`0Ω`；U3 pin 115 `CPU_DVDD`=`VDD_ARM_0V9`。
- 当前网表：R15/C25=`47 kΩ/100 nF`，R16/C26=`120 kΩ/100 nF`，R17/C28=`270 kΩ/100 nF`；R19=0 Ω连接 `VDD_1V35_EN` 和 `VDD_1V8_EN`。
- 公开阅读页截图：只可直接转述 `T0、T1 > 1 ms`、`T2 = 10 ms`、`Trise > 100 us` 以及各波形的相对关系。

**直接修文：** 用下文替换第 44、48、52、54 行对应段落；保留现有图 2-5～图 2-7。

> 公开阅读资料中标注为《RV1103G/RV1106G 硬件设计指南》V1.1 第 11 页的图 2-6，分别画出了 RV1106G 的 VDD_0V9、VDD_ARM、1.8 V、DDR、3.3 V 与 RESET 波形。图上可直接读到的时间标注是 T0、T1 大于 1 ms，T2 为 10 ms，电源上升时间 Trise 大于 100 us；不能把这些标注扩大成所有相邻电源边沿都满足同一个固定间隔。
>
> boomPI 用三组 RC 网络错开 U4 的使能。47 kΩ、120 kΩ和270 kΩ分别给100 nF电容充电；R19 又把1.35 V和1.8 V使能相连，因此 U4 表达的是0.9 V、1.35/1.8 V、3.3 V三个使能阶段。这里还要看到一个差别：R20用0 Ω把VDD_0V9接到VDD_ARM_0V9，CPU_DVDD没有单独的使能延时。因此这组电路只能说明三阶段设计意图，不能据此宣称已经逐项复现手册时序图。
>
> 4.7 ms、12 ms和27 ms只是三组RC的时间常数量级，不是电源到达时间。是否满足芯片要求，需要在同一次上电中同时观察VDD_0V9、R20后的VDD_ARM_0V9、1.35 V、1.8 V、3.3 V和nPOR；在取得这些波形前，本章不下“时序合规”结论。

### P1-2 两路麦克风不能直接称为“差分输入”

**位置：** Markdown 第 162 行；PDF 第 20～21 页。

**当前问题：** 文中写“随后接到 RV1106 的 MIC0 或 MIC1 差分输入”。U3 的确有 `CODEC_MIC0P/N` 和 `CODEC_MIC1P/N` 成对引脚，但当前板级接法不是未经限定的平衡差分麦克风：

- U9 pin 1 经 C57 接 `CODEC_MIC0P`，pin 2 经 C60 接 `CODEC_MIC0N`；但 U9 pin 2 又由 R49=0 Ω接地。
- U12 pin 1 经 C61 接 `CODEC_MIC1P`，pin 2 经 C62 接 `CODEC_MIC1N`；但 U12 pin 2 又由 R52=0 Ω接地。
- MIC0_P/MIC1_P 由 1.1 kΩ接 MICBIAS，符合两线模拟麦克风的偏置意图；这不等于已经形成“差分麦克风”或双麦阵列。

**影响：** 后续音频章如果沿用“差分输入”，可能错误配置 codec 或错误解释地线/信号线。

**直接修文：** 用下文替换第 162 行。

> 录音路线使用U9和U12两个2Pin连接器。每一路的P端经1.1 kΩ取得MICBIAS，并与N端一起通过隔直、滤波网络接到RV1106对应的CODEC_MICxP/N引脚；当前图中MIC0_N、MIC1_N还分别由R49、R52的0 Ω电阻接地。因此这里只能确认“两路带偏置的模拟麦克风连接”，不能把它写成平衡差分麦克风，更不能由两只连接器推出已经调好的双麦阵列。

### P1-3 40Pin 的结论正确，但用“HAT ID EEPROM 缺失”解释主板不兼容并不严谨

**位置：** Markdown 第 154 行；PDF 第 19～20 页。

**当前问题：** boomPI 在这里是带 40Pin 插座的主机板，不是插到 Raspberry Pi 上的 HAT/HAT+ 扩展板。ID EEPROM 本来应位于符合 HAT/HAT+ 的扩展板上，不能以“boomPI 原理图没有 HAT ID EEPROM”作为主板不能宣称兼容的直接理由。

真正尚未证明的是：boomPI 是否实现 Raspberry Pi 主机侧的 ID EEPROM 探测、全部引脚复用、上电状态、供电预算、机械空间与软件 overlay 行为。现有原理图只能确认物理位置和若干网络命名相近。

**一手依据：** Raspberry Pi *HAT+ Specification*，build-date 2024-12-05，PDF 第 3、5～7 页：HAT+ 是连接到主机 40Pin 的附加板，ID_SC/ID_SD 用于主机读取扩展板 EEPROM；只有满足规范的扩展板才可使用 HAT/HAT+ 标记。

**直接修文：** 用下文替换第 154 行中“HAT/HAT+”相关句子。

> 图纸采用与Raspberry Pi相近的2×20物理位置和常见电源脚，便于用杜邦线理解和连接；这只能称为Pi-like 40Pin布局。HAT/HAT+是扩展板规范，ID EEPROM应位于扩展板一侧。当前资料没有证明boomPI主机侧已经复现该规范要求的EEPROM探测、全部引脚复用、电源状态、机械空间和软件overlay行为，因此不能写成“完全兼容树莓派HAT/HAT+扩展板”。GPIO按3.3 V电压域使用，不能直接接入5 V逻辑信号。

### P1-4 摄像头模组“通常包含电源转换”不能替代准确模组资料

**位置：** Markdown 第 138 行；PDF 第 17～18 页。

**当前问题：** 当前 FPC1 只证明接口提供 3.3 V。SmartSens SC3336 V2.0 产品页给出的裸传感器电源包含 2.8 V模拟域和1.8 V I/O域；这说明外接模组**需要**在某处完成电源匹配，却不能证明尚未确认 MPN 的实际模组“通常还包含自身电源转换”。

**风险：** 初学者可能把裸 SC3336 或针序相似但没有稳压的模组直接接到 FPC1。

**直接修文：** 将第 138 行后两句替换为：

> 图中接口送出3.3 V，这不能直接接到SC3336裸传感器的各电源脚。3.3 V是否由外接模组转换成传感器所需电压，必须由该模组的准确料号和电路资料确认；确认前不要连接裸传感器或针序不明的20Pin模组。接线还要逐脚核对FFC方向、针序、复位极性和I²C电压域。
