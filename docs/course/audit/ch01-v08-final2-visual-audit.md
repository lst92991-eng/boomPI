## 6. 两项诚实证据缺口的阻断评估

### 6.1 无 boomPI 实拍

**对本轮逐章审阅稿：不阻断。**

理由：

- 当前正文没有展示其他开发板，也没有声称任何图片是 boomPI 实物；
- 硬件连接结论来自当前原理图和 `netlist`，没有用照片代替连接证据；
- 对外接屏幕、摄像头、触摸、麦克风和扬声器的边界写得清楚，没有把外接模组写成主板贴片件；
- 当前审阅任务可以评价文字、结构、框图、原理图和来源边界，不依赖实物照片才能开展。

**对正式完成：保留外部依赖。**

参考文档的开发板简介通常先展示真实对象，实拍会明显改善“先认识手里的板”这一教学动作。但在可信素材不可得时，缺图比假图更合格。关闭方式只有：由板卡持有者提供或现场拍摄可核对的 boomPI 正反面照片，并在加入后重做隐私和逐页检查。

不得用以下方式“关闭”：

- Luckfox 或其他 RV1106 开发板照片；
- 网络相似板、渲染图、AI 生成图；
- 仅凭接口外观相似就标为 boomPI；
- 把原理图框图改写成“实物布局图”。

若用户最终明确接受“无实拍版开发板简介”，可以把该项从正式门禁降为已知限制；审校智能体无权自行替用户作此取舍。

### 6.2 未找到官方 Hardware Guide 原 PDF

**对本轮逐章审阅稿：不阻断。**

理由：

- 当前截图本身可读，显示了 RESET、VDD_0V9、VDD_ARM、VCC_1V8、VCC_DDR、VCC_3V3 与 T0/T1/T2/Trise 条件；
- 图注给出手册全名、V1.1 和第 11 页，来源指向具体；
- 正文没有把手册时序写成本板实测，反而明确说 RC 时间常数不能证明实际波形已经满足手册；
- 本轮审阅可以继续检查因果、措辞和页面布局。

**对正式证据归档：仍需关闭。**

在当前工作区、Downloads 和 D 盘训练文档中只找到该页截图/裁剪，没有找到对应 V1.1 官方 PDF。因此目前能验证“截图展示了什么”，不能从工作区独立复核“截图是否逐像素来自指定官方文件”。

正式关闭条件任选其一：

1. 合规归档官方 PDF，记录文件名、版本、页码和 SHA256；或
2. 若授权不允许入库，在内部证据台账保存官方来源 URL、获取日期、文件 SHA256 和受限存放位置。

获得原文件后应从第 11 页直接重导图 1-4，不应对现有 735×590 PNG 做插值放大。当前图注无需恢复“待归档”字样，缺口应留在审计/证据台账中。
