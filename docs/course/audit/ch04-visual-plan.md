## 1. 读者与视觉目标

本章面对害怕技术词和长逻辑链的读者。视觉顺序应当是“先看一眼真实板端—一次只问一个问题—看到命令和回答—用一句话判断”，不做 Linux 概念图合集。建议正文 6～8 页、7～9 图，其中最多 1 张简单关系图，其余均为真实板端终端截图。

本章位于烧录和正式登录操作之前时，图 4-1 必须写成“先看一眼，不要求现在复现”；不要提前让读者配置 SSH，也不要把后续登录章的 Windows 界面重复搬入本章。
