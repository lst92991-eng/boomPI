# 第01章审校记录

## 本章主线

整板资源关系 → RV1106G3 官方能力 → 上电要求怎样落到电源与 RC 电路 → 启动介质与 USB 复用 → 原理图和 PCB 的边界。全章只有5个二级标题，连续讲完一条认识开发板的路线；更细的模块分析从第02章开始。

## 直接参考的原始文档行为

- `文本合格参考标准/1.Luckfox Pico Ultra W简介.docx`：参考其短开场、芯片事实直接进入正文、参数集中呈现，不继承其旧版 NPU 数值和其他板卡照片。
- `文本合格参考标准/第七章 BQ76952接口层 (1).docx`：参考其“从原理图划分模块，再回官方手册找设计依据”的推理方式；本章把这一方式用于 RV1106G3 上电时序和 RC 延时。
- `格式参考/尚硅谷嵌入式项目之UPS.docx`：参考 A4、标题、页眉页脚、正文、图注和表格样式，不继承过密的小标题。

## 官方与设计事实来源

- Rockchip RV1106 Datasheet Rev.1.8，第6页概述、第14页功能框图、第15页G3订货信息。
- Rockchip RV1106 官方产品页与 RV1106/RV1103 发布资料。
- 瑞芯微官方产品页：https://www.rock-chips.com/a/cn/product/RV11xilie/2022/0926/1661.html
- 瑞芯微 RV1106/RV1103 发布资料：https://www.rock-chips.com/a/cn/news/rockchip/2022/0217/1541.html
- 公开阅读资料中标注为《RV1103G/RV1106G Hardware Design Guide》V1.1 第11页的 RV1106G 上电时序截图。工作区没有对应完整官方原PDF，因此学生稿只转述页面标注，不写成已归档的官方原件。
- 本章归档的 `sources/SCH_Schematic1_2026-08-10.pdf` 与 `sources/netlist.json`。

## 已落实的用户反馈

- 整板框图不放器件位号，不放来源声明和限制说明。
- 原理图使用干净裁剪，不画红框、箭头或编号。
- 删除“画面处理流水线”和 1.6/1.7 式碎片内容。
- 芯片参数使用官方资料，G3 的 2 Gb DDR3L 明确换算为 256 MB，NPU 写为 1 TOPS。
- 手册上电时序使用官方原页裁剪，与四路电源和 RC 延时原理图相邻。
- 音频只说明板上预留，具体实现放在课程后段。
- 删除孤立收尾页，最终9页；修复“0 Ω”被分页拆开的排版问题。
- 清除 DOCX 中的外部模板、WPS设备标识和个人路径；9张正文图全部为嵌入式图片并带替代文字。

## 证据边界

本章说明芯片规格和原理图设计，不宣称所有板端资源已经通过。本轮硬件实测的通过、失败和阻塞状态统一在硬件测试章节给出。当前也没有可信 boomPI 正反面实拍，本章宁可不放实物图，也不使用 Luckfox、其他 RV1106 板或生成图冒充。
