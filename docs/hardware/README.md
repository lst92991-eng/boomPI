# 板级接口约束

硬件结论以当前板卡网表、DTS、驱动、匹配SDK和实机测量为依据，不从其他RV1106板或旧示例推断。

| 子系统 | 当前实现 |
| --- | --- |
| 采集 | Mode1，48kHz / S16_LE / 4ch，mic0、mic1、refL、refR |
| 声学处理 | 双麦和refL共同转16k，rkaudio_preprocess参数树，256点块适配320点交付 |
| 唤醒与VAD | Snowboy灵敏度0.7，WebRTC VAD mode 3，16k单声道 |
| 播放 | 16k mono TTS转48k stereo，左右相同 |
| 显示 | ST7789P3原生240×320转横屏320×240，SPI目标80MHz |
| 触摸 | GT911，I²C-3，地址0x14，固定复位时序和坐标旋转 |
| 网络 | 以太网优先，2.4GHz Wi-Fi备用 |

数字回采不等于扬声器实际声场。参考通道、极性、增益、延迟与麦克/扬声器位置需匹配本板；不能仅改采样率数字就宣称硬件支持16k双工。

两路PCM配置好后才开始采集。线程退出后释放资源；短读可以补足，断流前后的音频不能拼接。3A、Snowboy和VAD的错误必须传播，不能当作静音。

麦克风距扬声器的位置影响残余回声和插话。壳体、扬声器音量或安装位置改变后，需要重新确认近讲、双讲与误触发情况。GPIO、寄存器表和复位等待不能凭代码简化目标修改。
