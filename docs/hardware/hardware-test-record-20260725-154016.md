## 关键测试条件

### 音频

- 扬声器执行过单次播放、提高音量、数字音量 100 和循环播放，现场确认可听。
- 双麦经历过麦克风互换、主控更换和焊接复查，最终完成双通道基础录音。
- 本轮没有测量信噪比、频响、通道一致性、失真、延迟、AEC、波束形成或长稳。

### 网络

- 以太网直连完成 DHCP 和 SSH 密钥认证。
- Wi-Fi 完成 AP 配网原型及 STA 联网；测试时信号约为 -39 dBm。
- 凭据文件权限曾验证为 `0600`；本文不保存 SSID 密码或 API Key。
- NTP、DNS、HTTPS 和复杂断网恢复仍需在产品链路中回归。

### 显示与触摸

- LCD 分辨率为 240 x 320、RGB565，产品方向为 320 x 240 横屏。
- 运行时测试使用 SPI0 8 MHz 和屏幕厂商的 ST7789P3 初始化序列。
- 通用 `fb_st7789v` 初始化当时不能正确点亮模组；测试通过临时绑定
  `spidev` 完成，所以只能判定硬件链路通过。
- GT911 位于 I2C3 地址 `0x5d`，测试节点为 `/dev/input/event0`；坐标范围
  X=0..239、Y=0..319，最多五点。

### 摄像头

- SC3336 位于 I2C4 地址 `0x30`，输出 2304 x 1296 SBGGR10/RAW10，
  MIPI CSI-2 两条数据 Lane。
- 链路为 SC3336 -> CSI2 D-PHY -> MIPI CSI2 -> RKCIF -> RKISP。
- 从 RKISP 节点取得过 576 x 324 NV12 单帧，并转换为 RGB565 刷入 LCD；
  该测试证明基础采集与显示路径，不代表画质和帧率验收。

## 未覆盖范围

- 四通道全双工采集、数字播放参考、AEC/BF/VAD 和可打断对话。
- 24 小时并发稳定性、冷热启动、电源跌落、异常掉电和 Flash 寿命。
- 摄像头坏点、曝光、白平衡、暗光、帧率稳定性和多模态业务。
- LCD 正式驱动、目标刷新率、休眠唤醒和长时间刷新。
- ESD、EMI/EMC、功耗、热设计和量产可靠性认证。

## 判定

截至记录时间，扬声器、双麦、有线网络、Wi-Fi、LCD 基础显示、SC3336 和 GT911
具备继续进行 BSP 集成与上层应用开发的条件。该结论只代表工程样板的功能性
bring-up，不等同于产品验收或量产认证。
